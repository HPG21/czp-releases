# Changelog

## [1.11.0] - 2025-01-XX

### 🚀 Новые функции

#### 💰 Сверхурочные часы
- **Полная поддержка сверхурочных расчетов**
  - Ввод общего количества сверхурочных часов
  - Разделение на часы с доплатой 0.5
  - Разделение на часы с доплатой 1.0
  - Автоматический расчет выплат за сверхурочные

#### ⚙️ Гибкие настройки валидации
- **Новая настройка "Разрешить превышение часов"**
  - Можно включать/выключать строгую валидацию ночных и праздничных часов
  - При включенной настройке разрешается вводить ночные/праздничные часы больше рабочих
  - Автоматическое разрешение превышения при включенных сверхурочных

#### 📊 Аналитика сверхурочных
- **Новая карточка "Сверхурочные" в аналитике**
  - Статистика по сверхурочным часам и выплатам
  - Доля сверхурочных в общей зарплате
  - Настраиваемая видимость карточки

#### 🔧 Улучшенное редактирование
- **Полная поддержка сверхурочных в диалоге редактирования**
  - Редактирование всех параметров сверхурочных
  - Валидация с учетом настроек превышения часов

### 🎨 Улучшения интерфейса

#### 💡 Умные подсказки
- **Адаптивные подсказки в калькуляторе**
  - Подсказки учитывают настройку превышения часов
  - Убираются ограничения "Максимум: Xч" при включенной настройке

### 🔧 Технические улучшения

- **Улучшенная система сохранения настроек**
- **Исправлена валидация данных с учетом пользовательских настроек**
